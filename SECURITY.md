# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Report them privately through GitHub's repository security advisory workflow, if enabled, or contact the repository maintainer through the contact method listed on the GitHub profile.

Include a clear description, reproduction steps, affected paths or versions, potential impact, and suggested mitigation. Never include real user data, API keys, tokens, or secrets.

## Safe development

- Keep secrets in environment variables and out of Git.
- Use test accounts and synthetic data.
- Review authorization and consent changes carefully.
- Rotate credentials that may have been exposed.
