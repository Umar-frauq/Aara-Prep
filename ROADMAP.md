# AARA Prep Roadmap

This roadmap describes direction, not a promise of delivery dates. Priorities may change as the project is tested and maintainer capacity changes.

## Current focus

- Keep the application buildable and local setup understandable.
- Improve privacy, consent, and safety documentation.
- Stabilize check-in, journaling, insights, and report workflows.
- Make the codebase easier for contributors to navigate.
- Add focused tests around authentication, authorization, consent, and data handling.

## Next

- Improve error handling, loading states, accessibility, and responsive behavior.
- Document Firebase development and deployment setup.
- Add contributor-friendly issue labels and starter tasks.
- Review dependency health and remove unused integrations.

## Later

- Improve therapist-facing sharing and revocation flows.
- Add stronger observability and privacy-preserving analytics.
- Evaluate mobile and offline-friendly experiences.

## Out of scope

AARA Prep is not intended to diagnose, replace therapy, provide medical advice, or act as crisis care.
