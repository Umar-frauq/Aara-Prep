# Code of Conduct

We want AARA Prep to be a respectful, constructive, and inclusive project. Participants should communicate professionally and assume good faith while remaining open to correction.

Expected behavior includes respectful communication, feedback about ideas and code rather than people, protection of private information, and focus on improving the project.

Harassment, discrimination, threats, personal attacks, doxxing, and publishing private information without consent are not acceptable.

Report conduct concerns privately to the repository maintainer through the contact method listed on the GitHub profile. The maintainer may remove comments or restrict participation when needed.
